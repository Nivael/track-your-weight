# 轻一点 · Lighter Dashboard

一个中文、响应式、本地运行的健康记录面板。包含体重趋势、饮食记录、运动日历、恢复摘要、体型对比和手记时间线。

**本仓库只包含完全虚构的演示数据，不含真实用户记录、照片或聊天内容。** 示例目标及数值只用于 UI 演示，不构成健康建议。

## 运行

需要 Node.js 22.13+ 和 npm。

```bash
npm ci
npm run dev -- --hostname 127.0.0.1
```

打开 http://127.0.0.1:3000 。服务仅监听本机。

```bash
npm run build
npx tsc --noEmit
```

## 目录

- `app/`：页面、样式与只读 API。
- `demo/`：合成日志、手记和示例说明文档。
- `components/ui/`：界面基础组件。

照片模块保留，但不提供真实照片。空状态是预期效果。

## 隐私边界

读取目录固定为仓库内的 `demo/`，不会读取上一级目录。真实日志、照片、心路历程、健康症状、个人食谱、精确训练日程、身份标识和本机路径没有被复制。示例日期、体重和目标重新生成。开发缓存、运行日志、环境文件和部署配置不纳入版本控制。

不要将自己的私人数据写入受 Git 跟踪的示例文件。需要私人记录时，应使用仓库外的数据目录并保留本机访问限制。

## 技术

React、TypeScript、Vinext、Vite、Tailwind CSS、Base UI / shadcn 组件。
